# ⚖️ astrbot_plugin_user_agreement

AstrBot 用户协议与隐私政策同意管理插件。

---

## ✨ 功能

插件拦截所有消息，在用户同意协议**之前**不将消息传递给 LLM。

| 场景 | 行为 |
|------|------|
| 🆕 新用户首发消息 | 发送提醒文本 + 合并转发**用户协议**+**隐私政策** |
| 🔁 已提醒但未同意 | 仅发送简短提示，不重复刷屏 |
| ✅ 用户发送 `/同意` | 记录同意，放行后续消息 |
| 🔓 已同意用户 | 消息正常传递，零开销 |
| 🧹 管理员撤销 | 一键清空所有用户的同意状态 |
| ⌨️ QQ 输入态/退格 | 空消息不会触发任何回复 |
| 🛠️ 自定义指令 | 可配置任意同意/撤销指令 |

---

## 🚀 使用

```
用户视角                          管理员视角
─────────                        ─────────
发消息 ─→ 弹出协议卡片           发消息 ─→ 正常使用
/同意  ─→ ✅ 同意成功             /同意  ─→ ✅ 同意成功
发消息 ─→ 正常对话（放行）         /撤销所有同意 ─→ 🧹 重置全员
/同意  ─→ 提示「已同意」
```

---

## ⚙️ 配置

全部在 WebUI 插件配置页修改，无需编辑文件。

### 核心指令

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `agree_command` | `同意` | 用户发送此文字表示同意。始终支持 `/同意` `/agree` |
| `revoke_command` | `撤销所有同意` | 管理员撤销指令。始终支持 `/撤销所有同意` |

> **无论怎么改配置，`/同意` `/agree` `/撤销所有同意` 始终生效。**

### 文案自定义

| 配置项 | 默认值 |
|--------|--------|
| `reminder_text` | ⚠️ 您还未同意用户协议及隐私政策... |
| `repeat_reminder_text` | ⚠️ 您尚未同意...请发送 /同意 |
| `agree_success_text` | ✅ 您已同意...现在可以正常使用 |
| `already_agreed_text` | 您已同意过...无需重复操作 |
| `revoke_success_text` | ⚠️ 已撤销所有...需重新同意 |
| `revoke_no_admin_text` | ❌ 抱歉，只有管理员可以执行此操作 |
| `user_agreement_title` | 用户协议 |
| `privacy_policy_title` | 隐私政策 |

### 管理员

`admin_list` — 每行一个用户 ID。用户 ID 可从日志中获得（发送消息后控制台会显示 sender_id）。

## 📁 数据

- 同意列表持久化存储在 `data/plugin_data/astrbot_plugin_user_agreement/consented_users.json`
- 结构：JSON 数组，每项为用户 ID 字符串

```json
["1771818909", "3795672013"]
```

如需重置所有人，直接删掉此文件后重载插件即可。

---

## 🧬 技术说明

- 单一 `EventMessageType.ALL` handler，逻辑合并到 `on_all_message`
- 内置双重包装防御：`evt = args[0] if args else event`
- 空消息/空白消息不产生任何副作用（不会标记提醒状态）
- 已同意用户路径零开销（直接 `return`）
